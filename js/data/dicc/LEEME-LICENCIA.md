# Diccionario ortográfico del español (Honduras)

Los archivos `es_HN.aff` y `es_HN.dic` provienen del proyecto **RLA-ES**
(Recursos Lingüísticos Abiertos del Español), distribuidos con LibreOffice:

- Origen: https://github.com/LibreOffice/dictionaries (carpeta `es/`)
- Proyecto: https://github.com/sbosio/rla-es

Se distribuyen bajo un triple esquema de licencias disyuntas, a elección
del usuario: **GNU GPL v3 o posterior**, **GNU LGPL v3 o posterior**, o
**MPL v1.1 o posterior**. Este proyecto los usa bajo la **MPL 1.1**:

- https://www.mozilla.org/en-US/MPL/1.1/
- https://www.gnu.org/licenses/gpl-3.0.en.html
- https://www.gnu.org/licenses/lgpl-3.0.en.html

Los archivos se incluyen SIN modificaciones. El complemento local
`es_extra.dic` (léxico de la casa, hondureñismos y voces recientes) es
parte de este proyecto y sigue su misma licencia.

Todo el análisis ortográfico corre en el aparato: ninguna palabra del
texto sale hacia ningún servicio externo.
